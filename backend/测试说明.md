# 容器代码执行测试说明

## 🧪 测试方式

### 方式 1: 在 IDE 中直接运行测试类（推荐）

1. **打开测试文件**：
   ```
   backend/src/test/java/com/codelab/application/DockerCodeExecutionServiceTest.java
   ```

2. **确保环境准备**：
   ```bash
   # 1. 确保 Docker 已启动
   docker ps
   
   # 2. 确保沙箱镜像已构建
   docker images | grep c-codelab-sandbox
   # 如果没有，执行：
   docker build -t c-codelab-sandbox:latest ./code-sandbox
   ```

3. **运行测试**：
   - 在 IDE 中右键点击 `DockerCodeExecutionServiceTest` 类
   - 选择 "Run 'DockerCodeExecutionServiceTest'"
   - 或者运行单个测试方法

4. **查看结果**：
   - 测试会自动初始化容器池
   - 执行多个测试用例（Hello World、计算、编译错误等）
   - 显示详细的执行结果

### 方式 2: 使用 Maven 运行测试

```bash
cd backend
mvn test -Dtest=DockerCodeExecutionServiceTest -Ddocker.test.enabled=true
```

### 方式 3: 启动完整应用测试

```bash
cd backend
mvn spring-boot:run
```

应用启动后会：
- 自动创建容器池（约5-10秒）
- 容器保持运行状态

然后通过前端或 API 测试代码执行功能。

## 📋 测试内容

`DockerCodeExecutionServiceTest` 包含以下测试：

1. **容器池状态检查** - 验证容器池是否正常初始化
2. **Hello World** - 基本代码执行
3. **简单计算** - 验证输出
4. **编译错误** - 验证错误处理
5. **运行时错误** - 验证异常处理
6. **代码长度限制** - 验证输入验证

## ✅ 预期结果

### 成功的情况

```
容器池状态: PoolStatus(total=3, available=3, inUse=0)
=== 测试 1: Hello World ===
成功: true
输出: Hello, World!
退出码: 0
```

### 如果看到错误

1. **容器池初始化失败**：
   - 检查 Docker 状态
   - 检查镜像是否存在

2. **无法获取容器**：
   - 容器池可能已满
   - 检查容器是否都在运行

3. **执行失败**：
   - 查看详细错误信息
   - 检查容器日志：`docker logs codelab_pool_1`

## 🔍 查看容器池状态

```bash
# 查看容器池中的容器
docker ps | grep codelab_pool

# 查看容器日志
docker logs codelab_pool_1

# 进入容器检查
docker exec -it codelab_pool_1 /bin/bash
```

## 📝 注意事项

- 测试中配置为3个容器（比生产环境小，适合测试）
- 容器池会在 Spring Boot Test 启动时自动初始化
- 测试结束后，容器会继续运行（这是正常的，容器会被复用）
